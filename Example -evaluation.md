# Example: Evaluating an AI-Generated Scientific Response

## Scientific Question

What is the main function of mitochondria in a cell?

## AI-Generated Response

Mitochondria are organelles that produce most of the cell's ATP through cellular respiration.

## Evaluation

### Accuracy
The response is scientifically accurate.

### Completeness
The response correctly identifies ATP production as the main function, although mitochondria have additional roles in cellular metabolism and signaling.

### Overall Assessment
The response provides a concise and scientifically appropriate answer.

## Evaluation Criteria

- Scientific accuracy
- Completeness
- Clarity
- Presence of unsupported claims
